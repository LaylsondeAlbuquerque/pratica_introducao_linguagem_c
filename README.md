# Prática: Introdução à Linguagem C

![Linguagem C](https://img.shields.io/badge/Linguagem-C-blue.svg)

## 📖 Descrição

Repositório dedicado aos exercícios práticos da disciplina de **Introdução à Linguagem C**. Este projeto contém implementações dos conceitos fundamentais da linguagem, servindo como um registro do meu progresso acadêmico.

Este projeto faz parte da minha jornada de aprendizado no curso de **Análise e Desenvolvimento de Sistemas**.

---

## 📂 Estrutura do Repositório

O repositório está organizado em pastas, cada uma focada em um conceito específico da linguagem C:

* **/ola_mundo:**
    * O clássico "Olá, Mundo!" para verificar a configuração do ambiente e a sintaxe básica.

* **/declaracao_variaveis:**
    * Exercícios sobre a sintaxe de declaração, inicialização e uso dos tipos de variáveis (int, float, char, etc.).

* **/entrada_saida_dados:**
    * Práticas de como receber dados do usuário (entrada, ex: `scanf`) e exibir resultados no console (saída, ex: `printf`).

* **/tomada_de_decisao:**
    * Implementação de estruturas condicionais (como `if`, `else`, `else if` e `switch`) para criar programas com diferentes fluxos de execução.
